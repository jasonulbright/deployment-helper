# Keyboard

This page lists the Tab order and the keys of Deployment Helper.

## What it does

Every control can be reached with the keyboard. A focus frame shows the control that has the focus.

## When to use it

Use it to work without a mouse.

## Requirements

None.

## Steps

### Tab order of the Apps view

Select the **Apps** button in the sidebar, then press Tab. The focus goes in this order:

1. The sidebar buttons: **Packages**, **Task Sequences**, **Software Update Groups**, **Ring Deployment**, **Options**.
2. The **Apply Template** list.
3. The **Application** box and its **Browse...** button.
4. The **Collection** box and its **Browse...** button.
5. The purpose buttons **Available** and **Required**.
6. The two date fields, then the **Notification** list and the **Local time** button.

### Keys

| Key | Effect |
|---|---|
| Tab, Shift+Tab | Move the focus. |
| Enter, Space | Press the focused button. |
| Up, Down | Move in a list. |
| Esc | Close a dialog, as **Cancel**. |
| Shift+**Browse...** | Read the collections again from the site. |

## Limits

- The Tab order of the other views follows the layout.

## Troubleshooting

| Message or symptom | Cause | Fix |
|---|---|---|
| A button is skipped. | The button is hidden or disabled. | Run **Validate** first for **Deploy**. |
